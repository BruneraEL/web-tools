# Web Tools

Collection of lightweight web tools, PWAs, calculators, and utilities built to solve real-world everyday problems.

## About

This repository contains simple web-based tools designed to reduce repetitive tasks, improve decision-making, and streamline everyday workflows.

All projects are lightweight, fast, mobile-friendly, and designed to work with minimal dependencies.
